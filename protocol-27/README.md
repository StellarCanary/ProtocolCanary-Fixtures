# Protocol 27 pack

Intentionally empty.

Per this repository's contribution policy, a protocol pack is populated
only after its fixture inventory has been independently verified against
authoritative upstream sources — CAP text, upstream XDR, or official
release notes — for that specific protocol version. No placeholder or
dummy fixtures are added merely to fill this directory.

The current release targets Protocol 28 (see [`../protocol-28/`](../protocol-28/)
and [`../docs/protocol-28.md`](../docs/protocol-28.md)). A Protocol 27 pack
may be added in a future change once someone does that verification work.
